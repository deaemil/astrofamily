# Стартиране на Астро Атлас на macOS

1. Разархивирайте проекта. Отворете Terminal.
2. Необходими са Node.js 22.12+ и Python 3.12. Ако ползвате Homebrew:

   brew install node python@3.12

   Ако нямате Homebrew, официалният сайт е https://brew.sh.
   При липсващи инструменти за компилиране изпълнете:

   xcode-select --install

   Изчакайте инсталирането им, преди да продължите.

3. Отворете папката на проекта в Terminal. Ако архивът е разархивиран в Downloads:

   cd ~/Downloads/astro-atlas
   python3.12 -m venv .venv
   .venv/bin/python -m pip install -r server/requirements.lock
   npm ci
   .venv/bin/python scripts/ephemeris.py
   npm run dev

4. Оставете Terminal отворен и въведете http://localhost:5173 в браузъра на този Mac.
   За спиране натиснете Control+C в Terminal.

Може да използвате и bash scripts/install.sh за инсталация. Скриптът използва Python 3.12 и кеш в папката на проекта.
Локалният режим работи без Supabase. Данните се пазят в използвания браузър.
За облачен вход и база вижте README.md.

## Ако търсенето на място не работи

Търсенето и изчисленията се обслужват от Python сървъра. Не затваряйте Terminal след npm run dev.
Скриптът изчаква сървърът да е готов и е съвместим с macOS Bash 3.2.

За отделно стартиране (два прозореца на Terminal, и двата в папката на проекта):

Първи прозорец:

    .venv/bin/python -m uvicorn server.main:app --host 127.0.0.1 --port 8000

Втори прозорец:

    npm run dev:web -- --port 5173 --strictPort

После обновете страницата на http://localhost:5173, потърсете града и натиснете намерения резултат.
В обновената форма може да избирате и със стрелките и Enter. Въведеният текст сам по себе си не избира град.
Ако получите грешка за зает порт, спрете предишното стартиране с Control+C; не сменяйте порта, ако искате да запазите достъпа до локалните данни на същия адрес.
